# Индивидуальная часть проекта: *Caenorhabditis brenneri* (GCA_964036135.1)

Целью проекта является изучение ранней эволюции беспозвоночных на трех уровнях аннотации:
генетическом, эпигенетическом, и на уровне образования вторичных структур ДНК.

В качестве исследуемого организма была выбрана **нематода Caenorhabditis brenneri**.

### Общие сведения

**Caenorhabditis brenneri** — свободноживущая почвенная нематода, близкий родственник *C. elegans*.

### Информация об эпигеномике организма из открытых источников

**Гетерохроматин и метки:**
У *Caenorhabditis* виды, как и у *C. elegans*, гетерохроматин обогащён метками **H3K9me2/3** и **H3K27me3**. Кластеры с транспозонами и повторяющимися элементами подавлены через малые РНК и белки HP1-подобного семейства (HPL-1/2). У *C. brenneri*, как раздельнополого вида, предполагаются дополнительные механизмы регуляции половых хромосом.

**ДНК-метилирование:**
Каноническая система 5-метилцитозина (5mC) у *C. elegans* и близких видов отсутствует. Гены ДНК-метилтрансфераз C5 (*DNMT1/DNMT3*) не обнаружены. Вместо этого описано метилирование аденина (6mA), которое катализируется ферментами **DAMT-1** и **NMAD-1**.

**Метка 6mA:**
N6-метиладенин (6mA) встречается преимущественно в активных генах, в теле гена и в промоторных регионах, и связана с активацией транскрипции. Уровни 6mA динамически меняются в ответ на стресс и в ходе развития.

**Структура хроматина:**
Для *C. elegans* описаны ТАД-подобные домены (topologically associating domains) размером от сотен килобаз до нескольких мегабаз. По мере дифференцировки клеток меняется структура хроматина и профили гистоновых меток. У *C. brenneri* структура хроматина, вероятно, схожа, хотя детально не исследована.

**Гистоны и модификации:**
Присутствуют основные гистоны: **H2A, H2B, H3, H4**. Также имеются вариантные гистоны, характерные для нематод. Основные модификации гистонов, подтверждённые для *C. elegans* и предполагаемые для *C. brenneri*:

| Модификация | Функция |
|---|---|
| **H3K4me1/2/3** | Активная транскрипция |
| **H3K9me2/3** | Гетерохроматин, подавление |
| **H3K27ac** | Активные энхансеры |
| **H3K27me3** | Подавление (Polycomb) |
| **H3K36me3** | Элонгация транскрипции |
| **H4K5/8/12/16ac** | Открытый хроматин |

**Референсная сборка:** [`GCA_964036135.1_CAEBRE_CFB2252`](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_964036135.1/)

### Анализ генома

Анализ воспроизводится в ноутбуке [`brenneri.ipynb`](brenneri.ipynb).

## 3. Метод

| Этап | Инструмент / параметры |
|---|---|
| Скачивание данных | NCBI FTP, `*_genomic.fna.gz`, `*_genomic.gtf.gz`, `*_protein.faa.gz` |
| Эпигенетические гены | HMMER 3.3.2 `hmmsearch --cut_ga` по 16 профилям Pfam (InterPro API) против протеома; сопоставление с GTF по `protein_id` -> `gene_id` |
| G-квадруплексы | regex `(G{3,5}[ATGC]{1,7}){3,}G{3,5}` на обоих стрендах (на «−» C-паттерн), верхний регистр |
| Z-ДНК | `zhunt` (Ho Lab), `windowsize=12 min=8 max=12`, фильтр Z-Hunt score > 400 |
| Распределение по геному | `bedtools` (exons, introns, promoters = 1000 bp до TSS, downstream = 200 bp, intergenic) |
| Сравнение с фоном | `bedtools shuffle` (5 перестановок); обогащение = доля набл. / доля фон |

### Интерпретация

- **G4 и Z-ДНК (zhunt)** обогащены в **интронах** (1.57× и 1.14×) и **промоторах** (1.19× и 1.31×)
- Обе структуры **недостаточно представлены в экзонах** (G4: 0.24×, zhunt: 0.66×)
- **ZDNABERT** показывает обогащение в **экзонах** (1.20×), что может отражать особенности обучения модели
- Z-ДНК (zhunt) также обогащена в **интергенных участках** (1.08×)

Такое распределение указывает на связь этих структур с регуляторными районами и некодирующими последовательностями, что согласуется с их предполагаемой ролью в регуляции транскрипции и поддержании структуры хроматина.
